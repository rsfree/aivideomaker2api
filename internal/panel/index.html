官方 API

    

    
官方 REST（/api/v1/*）用 API Key 鉴权，没有 cookie、没有 Turnstile 闸门，
      并且多出 seedance20 / wan30 / happyhorse 等模型。720p 及以上走这条路，480p 仍走网页免费档。
